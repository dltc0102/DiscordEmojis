# DiscordEmojis

Converts text-based emojis in Minecraft's chat messages to graphical/image forms of emojis.
Environment: Only works in Minecraft 1.8 - 1.8.9 on mc.hypixel.net
Uses: https://github.com/dltc0102/biscuitsEmojiPack 

--- 
Given a text-based emoji like `:100:`, it would produce a given block of Chinese Unicode characters that Minecraft supports, and with the resourcepack dltc0102/biscuitsEmojiPack, will convert the chinese character to 💯.
